# What is the DECIDE-project about?

Basic information on the project can be found on the [website ](https://www.vlaanderen.be/lokaal-bestuur/digitale-transformatie/slimme-lokale-databronnen/over-decide)in Dutch, English and German. The webpage explains what the project acronym stands for, what the project is about, who the partners are, ... .



## Technical

On the following gitbookpages we dive deeper into the **technical information** about:

1. The [basic set up](write-up-uc0.0-data-space/) of the local decision and legislation (LD\&L) data space. Under this section you will specific pages on the pipelines we set up and the provenancetracebility, the way we tackle human in the loop and human validation, the set up of our DCAT catalogue, the use of DSP, VC's and ODRL and how we reuse the data quality manager of the Agency for Home Affairs. Finally we provide a repeatable data plan in case new partners want to join the data space.&#x20;
2. The [set up of a Policy Impact Report](write-up-uc0.1-policy-impact-report.md) on how local decisions and legislation can be linked to one of the 17 sustainable development goals and if that is expected to be a positiv or negativ impact.
3. The [reuse of location data](write-up-uc1-restricted-mobility-zones.md) in LD\&L and linking that to a restricted mobility zone if that is the case.
4. The use of LD\&L to set up a [smart search](write-up-uc2-smart-search.md)

All 4 use case have been set up with the help of one or more AI services. Specifications on these can be found in the write-ups of the use cases.&#x20;
