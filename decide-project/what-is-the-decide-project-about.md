# What is the DECIDE-project about?

Basic information on the project can be found on the [website ](https://www.vlaanderen.be/lokaal-bestuur/digitale-transformatie/slimme-lokale-databronnen/over-decide)in Dutch, English and German. The webpage explains what the project acronym stands for, what the project is about, who the partners are, ... .&#x20;

On the following gitbookpages we dive deeper into:

1. The basic set up of the local decision and legislation (LD\&L) data space.&#x20;
2. The set up of a Policy Impact Report on how local decisions and legislation can be linked to one of the 17 sustainable development goals and if that is expected to be a positiv or negativ impact.&#x20;
3. The reuse of location data in LD\&L and linking that to a restricted mobility zone if that is the case.
4. The use of LD\&L to set up a smart search&#x20;

All 4 use case have been set up with the help of one or more AI services.&#x20;
